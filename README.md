# 🌿 GREENDEN – Plant Store Website

A simple and responsive **plant store website** built using **HTML, Tailwind CSS, and JavaScript**.

Greenden provides a clean and modern interface for browsing plants, viewing products, and contacting the store.

## 🚀 Features

* 🌱 Responsive plant store website
* 🏠 Home page with:

  * Hero section
  * About Us section
  * Best Sellers
  * Customer Reviews
  * Newsletter subscription
* 🛍️ Product page with multiple plant products
* 🔎 Product search interface
* 📞 Contact page with contact form
* 📱 Responsive navigation bar
* ☰ Mobile side navigation menu
* 🎨 Tailwind CSS styling
* ✨ Hover effects and responsive layouts
* 🖼️ Product and header images

The Home page includes plant categories, best-selling products, reviews, and a newsletter section.

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **SVG Icons**
* **Responsive Design**

Tailwind CSS is loaded through the CDN in the HTML files.

## 📱 Responsive Design

The website uses Tailwind CSS responsive utility classes to adapt the layout for different screen sizes.

The desktop navigation is replaced with a mobile menu icon on smaller screens.

## ☰ Mobile Navigation

JavaScript controls the mobile side navigation.

When the menu icon is clicked, the side navigation moves into view, and clicking the close button moves it back out of view.

## ▶️ How to Run

1. Download or clone the project.

2. Make sure the project structure is maintained.

3. Open the project folder in **Visual Studio Code**.

4. Open `intex.html` in your browser.

5. Navigate between:

   * Home
   * Product
   * Contact

### Recommended

Use the **Live Server** extension in VS Code for the best development experience.
